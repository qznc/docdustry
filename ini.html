The ini file

Docdustry uses an INI configuration file (typically named docdustry.ini) to control document generation and serving behavior. The configuration file uses standard INI format with sections and key-value pairs.

inclusion

Complete ini Example

Here's a complete example configuration file:

[gen]
output: out/
sources: docs/
sources: spam/
frontpage: frontpage
theme: my-theme.css

[serve]
default: index
theme: theme/default/
title: Here to Serve

Configuration Section Reference

inclusion

[gen] Section

  • output specifies the output directory where generated HTML files will be placed.
  • sources specifies source directories containing Markdown files to process. You can specify multiple source directories by repeating the sources key on separate lines. All .md files in these directories will be collected and processed.
  • frontpage defines the document ID to use as the frontpage of the generated documentation.
  • theme specifies the CSS theme file to apply to the generated documentation.

[serve] Section

  • frontpage sets the default page to display when serving the documentation.
  • theme specifies the theme directory for the server.
  • title sets the title for the served documentation that appears in the browser.
