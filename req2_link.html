DocDustry supports direct link inclusion

One file can include another one. Thus, we can keep files short and still build large documents.

Simplest way is an img link to a document id:

![include](did:foobar)
doc meta info
id: req2_link
status: accepted
tag: requirement
derived_from: req2
  • req2 links this
  • this derived_from req2
  • req2
