[gen] Section

  • output specifies the output directory where generated HTML files will be placed.
  • sources specifies source directories containing Markdown files to process. You can specify multiple source directories by repeating the sources key on separate lines. All .md files in these directories will be collected and processed.
  • frontpage defines the document ID to use as the frontpage of the generated documentation.
  • theme specifies the CSS theme file to apply to the generated documentation.
