## Creating New ADRs

1. Create a new file in `docs/arch/decision/` with format `NNN-short-title.md`
2. Use the next sequential number
3. Structurally follow [this blog post](https://beza1e1.tuxen.de/decision_records.html)
4. Add appropriate docmeta with unique ID
5. Link from this index page

```docdustry-docmeta
id: arch_decisions
tag: arc42
```

See [Arc42 Decision hints](https://docs.arc42.org/section-9/).
